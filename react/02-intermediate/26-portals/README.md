# Portals

This app explores `createPortal`: `Modal` renders its children into the
`#modal-root` DOM node (declared in `index.html`) instead of wherever it's
called from in the component tree, while still behaving like a normal
React child (state, events, and context still work as expected).

## Getting started

```
bun install
bun run dev
```

Then open http://localhost:5173 or Start Debugging with VSCode.
